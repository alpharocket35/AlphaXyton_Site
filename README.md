# AlphaXyton — site officiel

Site vitrine statique d'AlphaXyton, le projet commun de **AlphaRocket35** et **Alexyton35**.

## Contenu

- `index.html` — structure du site
- `style.css` — design responsive, sombre, glass/dark et animations
- `script.js` — menu mobile, animations d'apparition et année automatique
- `assets/logo.jpg` — logo officiel fourni
- Aucun backend, aucune base de données, aucun compte nécessaire.

## Déploiement sur GitHub Pages

1. Créez un dépôt GitHub (par exemple `AlphaXyton`).
2. Décompressez ce projet et placez **le contenu du dossier `AlphaXyton`** à la racine du dépôt.
3. Faites un commit puis poussez les fichiers sur GitHub.
4. Dans **Settings → Pages**, choisissez le déploiement depuis la branche principale (`main`) et le dossier `/ (root)`.
5. Enregistrez. GitHub Pages publiera automatiquement le site.

Le projet utilise uniquement HTML, CSS et JavaScript côté navigateur et est donc adapté à GitHub Pages.
